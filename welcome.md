# EVILSAAD JUPYTER

Welcome to your browser-based Python workspace.

- **Notebook:** create and run `.ipynb` files.
- **Terminal:** use the JupyterLab Launcher to open a terminal.
- **Python:** Python 3 with NumPy, pandas, Matplotlib, seaborn, SciPy and scikit-learn.
- **Git:** Git is installed in the container.

## Important deployment notes

1. Keep `JUPYTER_TOKEN` secret. Anyone with the token can access your workspace.
2. Render's free service may sleep and its filesystem is ephemeral. Use a paid persistent disk if you need files to survive redeploys/restarts.
3. This is a single-user Jupyter workspace, not a multi-account hosting panel.
